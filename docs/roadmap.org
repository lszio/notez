#+title: Notez Roadmap
#+STARTUP: showeverything

* 基线状态
当前实现已具备 Rust 模块化单内核、Org/Markdown 扫描、SQLite 投影、CLI/MCP、来源挂载、附件、社区、派生产物及 folder/relay 同步的纵向切片。主要技术债是配置分散以及 CLI/MCP 能力漂移（无损链接与稳定身份的债务已在 0.3 中解决）。

* 里程碑计划

** DONE 0.3：无损链接与稳定身份
CLOSED: [2026-07-24]
- [X] 交付 =LinkTarget=、=LinkOccurrence=、=ResolvedRelation= 和 =ResourceAddress=。
- [X] 支持 Org、标准 Markdown 与 Obsidian 默认 profile，保真提取所有链接目标。
- [X] 加入确定性派生身份算法 (=derived_id=)，确保无 ID 资源身份稳定。
- [X] 提供链接诊断能力（CLI/MCP =link list= 和 =link resolved= 命令）。
